# Rebuild-RONA

RONA is an iOS application that helps people understand changes in their skin condition over time by turning repeated face scans into a clear progress story.

This repository contains the **new codebase for the RONA rebuild**, created from the existing product experience and requirements. The rebuild focuses on improving the interactive experience while re-establishing the application architecture around the current product scope.

> RONA is a tracking and progress-understanding experience, not a medical diagnosis or treatment tool.

---

## Product Context

RONA helps people with recurring acne understand whether their efforts are producing meaningful changes over time.
